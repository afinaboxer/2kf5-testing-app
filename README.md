1. Как работают маршруты (React Router)
В App.tsx у нас есть <Routes>. Это как сортировщик на почте. Он смотрит на адрес в браузере (URL) и решает, какой компонент показать.

Если адрес /admin, он берет <AdminLayout />.

Внутри AdminLayout есть <Outlet />. Это дырка, куда сортировщик вставляет вложенные страницы.

Если адрес /admin/tests, сортировщик берет AdminLayout (рамку), а в «дырку» (Outlet) вставляет <AdminTestsPage />.

2. Как работает состояние (useState)
Смотри на свои страницы (например, ProfilePage.tsx). Там написано:
export function ProfilePage() { return (...) }.
Функция возвращает (return) HTML-код (JSX). React берет этот HTML и рисует его на экране.
Если бы у нас был инпут (как в том коде с useState, который ты показывала в самом начале), то useState создавал бы «коробочку» с памятью, где хранится то, что ввел пользователь.

3. Как работают стили (Emotion)
Когда ты пишешь:

tsx
const Wrapper = styled.div`
  display: flex;
`
Ты создаешь новый компонент (как будто создала <div>, но с готовыми стилями). Ты передаешь Emotion'у обычный CSS, а он превращает его в React-компонент. Потом ты просто пишешь <Wrapper>, и он сам применяет эти стили. Никаких классов из App.css не нужно.

Посмотри на свой src/App.tsx. Как он работает?

Что передается? Ты пишешь <Route path="/admin" element={<AdminLayout />}>. Ты передаешь в свойство element компонент AdminLayout.

Что откуда берется? React Router смотрит на адресную строку браузера. Если там написано localhost:5173/admin, он берет AdminLayout и рендерит его на экране.

Как работает Outlet? AdminLayout — это рамка. Внутри рамки есть <Outlet />. React Router берет вложенный маршрут (например, tests) и вставляет его в эту рамку. Поэтому слева меню остается, а справа меняется текст.

Видишь? Никакой магии. Просто "откуда берется адрес" -> "какой компонент показать" -> "куда его вставить".
